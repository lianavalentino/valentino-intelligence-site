# valentino-intelligence-site

**Purpose:** Public portfolio site for Valentino Intelligence LLC (Liana's AI consulting). Shareable link for prospects.

**Stack:** Next.js (App Router) + TypeScript + Tailwind. Static, no backend. Deployed on Vercel. Repo: github.com/lianavalentino/valentino-intelligence-site.

**State:** scaffolded 2026-09-11, first version built same day for a prospect call. Quick and dirty by design.

**Constraints:** no client credentials, PII, or internal process detail beyond what `content/` says. Case-study facts must match `~/Developer/career-ops/knowledge-base/03 Project Portfolio.md`. Do not invent outcome numbers.

**Where this connects:** nothing. Standalone. Domain valentinointelligence.com (Cloudflare) not yet pointed.
